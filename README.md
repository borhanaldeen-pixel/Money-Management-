# المنظومة المالية — تطبيق PWA

## محتويات المجلد
| الملف | وظيفته |
|---|---|
| `index.html` | التطبيق نفسه (مع وسوم PWA وخط Cairo المحلي وتسجيل الـ Service Worker) |
| `manifest.webmanifest` | بيانات التطبيق: الاسم، الألوان، الأيقونات |
| `sw.js` | يخزّن الملفات ليعمل التطبيق بدون إنترنت |
| `icon-192.png` / `icon-512.png` / `icon-maskable-512.png` | أيقونات أندرويد والمتصفحات |
| `apple-touch-icon.png` | أيقونة آيفون |
| `cairo-arabic.woff2` / `cairo-latin.woff2` | خط Cairo محليًا (بدلًا من Google Fonts) |

## الرفع على GitHub Pages
1. ارفع **كل الملفات** إلى نفس المجلد في المستودع (بجانب `index.html`).
2. فعّل Pages من: Settings ← Pages ← Branch: main.
3. افتح الرابط (HTTPS) مرة واحدة وأنت متصل بالإنترنت ليُخزَّن التطبيق.

> لا يعمل التثبيت ولا الـ Service Worker عند فتح `index.html` مباشرة من الجهاز (file://)، يجب أن يكون التطبيق على رابط HTTPS.

## التثبيت
- **أندرويد (Chrome):** القائمة ⋮ ← «تثبيت التطبيق».
- **آيفون (Safari):** زر المشاركة ← «إضافة إلى الشاشة الرئيسية».

## ملاحظات مهمة
- **البيانات:** تُحفظ في localStorage على الجهاز. إذا غيّرت الرابط، أو ثبّتّه على آيفون، فقد يبدأ التطبيق فارغًا؛ لذلك خذ نسخة احتياطية من زر «النسخ الاحتياطي» داخل التطبيق ثم استعدها في التطبيق الجديد.
- **تحديث التطبيق:** بعد أي تعديل على الملفات غيّر VERSION في أول sw.js (مثلًا v2) ثم ارفع الملفات.
